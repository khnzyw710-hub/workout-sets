# אימון סטים

טיימר אימון כושר אישי - PWA (רץ בדפדפן, מותקן למסך הבית בטלפון בלי חנות אפליקציות).

## מה זה עושה

10 סטים ברצף. בכל סט: דקה אחת לבצע 10 חזרות בטן, 10 שכיבות סמיכה, 10 סקוואטים ו-10 חזרות תרגיל שוקיים (לתאומים) - ואז שתי דקות מנוחה לפני הסט הבא (אין מנוחה אחרי הסט העשירי).

- טיימר גדול עם טבעת התקדמות, ניתן לקריאה מרחוק.
- מעבר אוטומטי בין ארבעת התרגילים בתוך כל סט (15 שניות לכל תרגיל), עם אייקון וסימון מי כבר בוצע.
- צלילים שונים לתחילת עבודה, תחילת מנוחה, ספירה לאחור של 3 שניות אחרונות, מעבר בין תרגילים, וסיום האימון - נוצרים ב-Web Audio, בלי קבצי סאונד חיצוניים.
- רטט (בטלפון עם תמיכה) בנקודות מעבר.
- המסך נשאר דלוק תוך כדי אימון (Screen Wake Lock).
- כפתור השהיה/המשך, כפתור דילוג לשלב הבא, וכפתור עצירה עם אישור.
- מעקב היסטוריה: כמות אימונים שהושלמו, רצף ימים רצופים, רשימת האימונים האחרונים - נשמר מקומית בדפדפן (localStorage).
- עובד אופליין אחרי טעינה ראשונה (Service Worker).

## איך להשתמש

**מהטלפון:** לפתוח את הכתובת למטה בדפדפן, ואז "הוסף למסך הבית" (Android כרום: תפריט שלוש נקודות, iPhone ספארי: כפתור שיתוף) - האפליקציה תיפתח כמו אפליקציה רגילה, במסך מלא.

**מהמחשב:** קיצור בדסקטופ "אימון סטים" פותח את האתר בכרום.

## מבנה

```
index.html    מסכי האפליקציה (בית / אימון / סיום)
styles.css    עיצוב Dopamine - צבעים רוויים, טיימר עגול, מסגרות עבות
app.js        כל הלוגיקה - טיימר, שלבים, צלילים, היסטוריה
icons.js      אייקוני קו מצוירים ביד לכל תרגיל (SVG, בלי אימוג'י)
manifest.json + sw.js    תמיכת PWA - התקנה למסך הבית ועבודה אופליין
icons/        אייקוני האפליקציה (PNG, נוצרו מקומית)
```
